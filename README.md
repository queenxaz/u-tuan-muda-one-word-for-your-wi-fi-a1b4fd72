Entry: **Gaslighting** — 11 characters, one word.

It says it is connected. Nothing loads. You restart the router, it
says it is connected. The word for a network that denies your reality
while failing in front of you is gaslighting, and it is the truest
single word this Wi-Fi has ever earned.

## Run

```sh
python3 main.py
```

No network, no arguments, no secrets. The program writes the word to
`/output/entry.txt`.
